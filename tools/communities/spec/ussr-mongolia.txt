# Between Frontiers — population composition on 1925-01-01, region SOV (USSR, Tannu Tuva, Mongolia)
# Base: All-Union census of 17 Dec 1926 (vol. 9-17, Table VI "population by sex and nationality"),
# read at guberniya/okrug/ASSR level from the Demoscope Weekly transcriptions. Shares are of total
# population incl. foreign citizens; foreigners are allocated to the nationality they mostly were
# (Chinese/Korean columns in the Far East, Persian subjects in Transcaucasia/Turkmenia).
# 1926 is taken as close enough to 1925-01-01 (two years; no border change inside the Union that
# moves these units, except the 1924-25 Central Asian delimitation already in force).
# No religion question in 1926: religion by tradition of each nationality (flag M). Conventions:
#   Russians, Ukrainians, Belarusians, Old Believers -> orthodox; Kryashens and Nagaibaks (baptized
#   Tatars) -> tatar/orthodox; Chuvash, Mordvins, Komi, Karelians, Veps -> orthodox; Mari and
#   Udmurts split orthodox/folk where unbaptized communities were large (Bashkiria, Mari AO);
#   Volga/Siberian Tatars, Bashkirs, Kazakhs, Central Asians, North Caucasians (except Ossetians)
#   -> sunni; Azerbaijanis split shia ~70% / sunni ~30% (north-west sunni); Talysh, Tats, Kurds of
#   Transcaucasia -> shia, Yazidis -> kurdish/yazidi; Ossetians orthodox with a sunni (Digor) minority
#   in North Ossetia; Abkhaz split orthodox/sunni; Ajarians and Laz -> georgian/sunni;
#   Armenians -> oriental_orthodox; Georgians incl. Mingrelians and Svans (census sub-groups of
#   Georgians) -> orthodox; Jews: Yiddish-speaking -> ashkenazi/jewish; Mountain Jews (Judeo-Tat)
#   and Bukharan/Central Asian Jews (Judeo-Tajik) -> mizrahi/jewish (Persian-speaking); Georgian Jews
#   -> georgian/jewish (Georgian-speaking); Krymchaks and Karaites -> crimean_tatar/jewish
#   (Turkic-speaking; Karaites are not rabbinic but are Judaic); Germans: Volga Lutheran ~70% /
#   Catholic ~30%, Black Sea colonies (Odessa, Mykolaiv) half Catholic, Volhynia, Molochna,
#   Chortitza, Crimea, Siberia, Kazakhstan Lutheran/Mennonite -> protestant; Kalmyks, Buryats of
#   Transbaikalia, Tuvans, Mongols -> vajrayana; western (Irkutsk) Buryats -> folk; Yakuts split
#   orthodox/folk; Siberian and Far Eastern small peoples -> folk; Koreans -> folk, with an
#   Orthodox share among Soviet-citizen Koreans of the Far East; Chinese -> han/chinese_folk.
# Census nationalities merged (<= 10 entries per line): Mishars, Teptyars, Siberian "Bukhartsy" ->
#   tatar; Besermyans -> udmurt; Kurama, Kipchaks, Fergana "Turks" -> uzbek; Taranchi, Kashgarliks,
#   Uyghurs -> uyghur; Andi-Dido peoples -> avar; Kaitaks, Kubachi -> dargin; Tabasarans, Rutuls,
#   Aguls, Tsakhurs -> lezgin; Altaians, Telengits, Teleuts, Kumandins, Oirats -> altai; Evenks,
#   Evens (Lamuts), Nanais, Ulchs, Udege, Negidals, Orochi, Oroks, Samagirs -> tungusic.
# Groups under 0.5 % are folded into the nearest listed community (same religion first) unless
# they carry a relevance factor (Poles: patron).
#
